Etapa 2

Conferência da rodada

Cada venda do arquivo termina em um destino. Nada fica para trás sem explicação.

Etapa 3

Baixa dos títulos

A baixa é o que faz o Bauner emitir as notas fiscais. Confira os números antes de gerar.

Exporte com todos os status, para o sistema reconhecer o que já foi liquidado.

Carga de clientes atrasados
